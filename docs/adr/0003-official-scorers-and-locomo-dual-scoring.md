# Scoring reuses the official Python scorers; LoCoMo is dual-scored

The Harness (Go) orchestrates ingestion and retrieval, but scoring shells out to each Benchmark's official Python implementation so our numbers are computed by the exact code the papers used; only trivial deterministic metrics may be ported to Go. Comparability with published numbers is the point of adopting known Benchmarks, and a hand-ported Judge that drifts a few percent invalidates every comparison. LoCoMo specifically is dual-scored: its official lexical QA metric (F1 only — verified 2026-09-01 against snap-research/locomo's `task_eval/evaluation.py`: BERTScore is uncalled dead code and ROUGE-L backs only the separate dialogue-generation task) for paper parity, plus a pinned Judge for paraphrase-tolerant tracking — both recorded in every Report. Vendor-published LoCoMo numbers are never cited without re-running them under our own Judge (judge choice is why public Mem0-vs-Zep numbers contradict each other).
